# Data model

Built by dbt (`dbt/`) from the silver lake tables. It runs on DuckDB locally and on BigQuery in prod.

```
bronze (raw, immutable) → silver (typed Parquet) → staging → intermediate → marts
```

## Marts

| Table | Grain | Coverage | Highlights |
|---|---|---|---|
| `fct_matches` | season × home × away | 2014-15 → now, 380/season | Result and UTC kickoff (FPL). Understat xG and Opta xG/xGOT. Opening and closing odds with **margin-free implied probabilities**. Understat forecast, Elo. |
| `fct_player_matches` | season × player × fixture | 2016-17 → now (incl. 0-minute squad rows) | FPL events, points, BPS/ICT, price, ownership and transfers. FPL xG/xA from 2022-23. Defensive stats from 2025-26. Opta touches, chances created, xGOT and duels from 2024-25. |
| `dim_teams` | club | 36 clubs | Each source's identifier (FPL code, football-data name, Understat id) |
| `dim_players` | player (`player_code`) | 2,758 players | Stable across seasons; latest name and position |

## Keys

- **`team_key`:** a slug that is stable across seasons. The crosswalk seed is generated by `dbt/scripts/build_team_crosswalk.py`.
- **`player_code`:** FPL's stable player id. `element` is only unique within a season.
- **`match_key`:** a hash of (season, home `team_key`, away `team_key`).
- **`player_match_key`:** a hash of (season, element, FPL fixture id).

## Guarantees (dbt tests)

| Guarantee | Severity |
|---|---|
| Exactly 380 matches per season (a club mapping error would add rows) | error |
| FPL, football-data and Understat agree on every shared score; FPL and football-data on every played date | error |
| Every finished match: players' goals + opponents' own goals = the official score | error |
| Every player row belongs to one side of its match, consistent with `is_home` | error |
| Keys unique/not-null; every club mapped; relationships between marts | error |
| Elo-Insights scores (6 known wrong) and Understat dates (kickoffs off by −12..+8h) | warn |
| Opta coverage of finished player-matches from 2024-25 | warn |

## Caveats for modelling

- **Points:** `total_points` uses each season's rules (e.g. defensive contributions from 2025-26). Model scoring *events* and apply the current rules.
- **2019-20 gameweeks** run 1–29 then 39–47 (COVID). Order matches by `kickoff_utc`, not by gameweek.
- **2014-15 and 2015-16** have Understat only: no FPL ids, and dates may be a day out for evening games.
- **Current-season rows** come from the latest daily snapshot. Rows with `is_provisional` are for unfinished fixtures (bonus not confirmed).
